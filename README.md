# Meridian Watch Store

A responsive luxury watch storefront preview made with plain HTML, CSS and JavaScript.

## Open locally

Open `index.html` in a web browser. No dependencies or build step are required. Photographs are loaded from Unsplash and require an internet connection.

## Included

- Responsive storefront with three illustrative watch listings
- Product detail dialogs
- Shopping bag with quantity controls, removal and calculated subtotals
- Keyboard-accessible dialogs and controls
- Custom favicon and page metadata
- Optional browser WebMCP tool for adding a sample watch to the bag

## Before selling

Replace the placeholder Meridian name, illustrative prices, sample product descriptions and photography with your own brand and accurate catalogue. Connect a payment provider and order processing before accepting purchases. The current version explicitly identifies itself as a preview and does not take payments or orders. Shopping bag state lasts for the current page session.
